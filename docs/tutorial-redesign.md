# Редизайн учебника «Скажи домашку»: задание и статус

Документ описывает текущую задачу по переделке `docs/tutorial.md` в стиль
учебников O'Reilly (Head First) и фиксирует, что уже сделано, а что осталось.
Обновляется по мере продвижения работы.

---

## 1. Задание (спецификация редизайна)

### Цель

Переписать `docs/tutorial.md` (14 глав + заключение) так, чтобы текст читался как
учебник издательства O'Reilly из серии Head First — «Изучаем Python»: вовлекающий,
с метафорами и упражнениями, технически строгий. При этом весь технический
контент и точность кода (сверка с реальным репозиторием) сохраняются.

### Решения, принятые пользователем

| Вопрос | Решение |
|--------|---------|
| Обращение | «Вы» (вежливое) |
| Эталон стиля | Head First / «Изучаем Python» |
| Объём правки | Полный редизайн: тон + типовые блоки + компоновка глав, упражнения |

### Структура каждой главы (в новом стиле)

1. **Шапка главы** — эмоциональный заголовок-интрига + блок «В ЭТОЙ ГЛАВЕ:» со
   списком вопросов, на которые глава ответит.
2. **Открывающая сцена/метафора** — история или образ, зацепляющий тему.
3. **Каллауты-блоки** (аналог Head First):
   - «Вопросы любопытных» — Q&A с реальными недопониманиями новичков;
   - «Без паники» — объяснение пугающего (async, отмена задач, исключения);
   - «Совет» / «Важно» / «Предупреждение» — практические замечания;
   - «Термин» / «Аналогия» — глоссарные и образные врезки.
4. **Упражнения** — «Попробуйте сами [✎]»: открыть файл, построить цепочку,
   предсказать ответ, проверить руками.
5. **Концовка главы** — «Итоги главы» (5–7 тезисов) + «Проверьте себя» с
   ответами под «Решения».
6. **Сквозные метафоры по книге**: эстафета-запрос (гл. 2), кухня-воркер
   (гл. 8), «карта сокровищ» (гл. 1), — повторяются из главы в главу.

### Процесс (две итерации ревью на каждую главу)

- **Шаг A** — переписать главу в новом стиле (сохраняя код и факты).
- **Шаг B** — итерация 1 ревью-исправлений: вычитать главу против стилевого
  чека, исправить отступления.
- **Шаг C** — итерация 2 ревью-исправлений: вторая полная вычитка + фиксы.
- **Шаг D** — общий прогон на русский язык по всей книге: орфография,
  пунктуация, согласование «Вы», «в»/«во», числительные, отсутствие канцелярита.
- **Финал** — проверка UTF-8 и прогон `tests/test_encoding.py`.

## 2. Техническая база (факты для сверки текста)

Эти факты — источник правды при написании глав; они выверены по исходникам.

- Тестов: **78**, файлов 8: `test_config`, `test_homework`, `test_cache`,
  `test_worker`, `test_sgo`, `test_handlers`, `test_skill`, `test_encoding`.
  Общего `conftest.py` **нет** — хелперы-заготовки живут прямо в файлах тестов.
- `test_encoding.py` сканирует только `alice_skill/`, `tests/` (*.py),
  `README.md`, `config.example.json`. `docs/` не сканируется.
- Реальные сигнатуры (использовать в листингах):
  - `answer_from_cache(cache: HomeworkCache, worker: PrefetchWorker) -> Response` —
    **синхронная** `def`, без параметра `message`, без кнопок; условие
    `result.status in ("ok", "empty")`; при пустом кеше вызывает
    `worker.refresh_now()` и возвращает `PREMATURE_TEXT`.
  - `PrefetchWorker`: `start()`/`stop()` — `async`, `refresh_now()` — обычный
    метод; `stop()` гасит задачу через `contextlib.suppress(CancelledError)`.
  - `HomeworkCache` — dataclass; хранит один `HomeworkResult` + `_fetched_at`.
  - Хуки в `skill.py`: `@dp.startup()`, `@dp.shutdown()`, `@dp.timeout()`,
    `@dp.errors()`; webhook: `request_handler.register(app, path="/alice")`,
    `setup_application(app, dp, skill=skill)`, `app["dispatcher"] = dp`.
- Фразы `common.py`: `PREMATURE_TEXT`, `HINT_TEXT`, `TIMEOUT_TEXT`,
  `ERROR_TEXT`; `ERROR_TEXT` также экспортируется из `sgo.py`.
- В локальном окружении не установлен `aliceio` (нет в активном Python), поэтому
  полный `python -m pytest` падает на импорте `test_skill.py`/`test_handlers.py`;
  изолированно проходит `tests/test_encoding.py` (25 тестов). В README заявлено 78.
- Уже внесённые ранее (до редизайна) правки точности в главах 5–14 считаются
  актуальными: у глав 3–14 стиль старый, но факты выверены.

## 4. PDF-сборка

- Скрипт: `docs/pdf/build.js` (+ `package.json`, `fonts/` Noto Sans,
  `.gitignore`). Запуск: `cd docs/pdf && npm install && npm run build`.
- Вход: `docs/tutorial.md` → выход: `docs/tutorial.pdf` (A4, 55 стр. на текущем
  состоянии текста).
- Оформление: обложка, содержание с чипами, открывающие блоки «В ЭТОЙ ГЛАВЕ»,
  каллауты-панели, блоки кода с ярлыком языка и подсветкой, футер с номером
  страницы. Превью: `PREVIEW=1 node build.js`.
- Требования: Node.js, `npm install`, установленный Google Chrome (путь через
  `CHROME_PATH` или фиксированный `C:\Program Files\Google\Chrome\...`).
